Biblioteca de recursos distribuídos com o site.

Arquivos pequenos e necessários ao site podem ser colocados aqui. Modelos 3D grandes (200–300 MB) devem permanecer no computador durante o desenvolvimento e ser servidos por armazenamento dedicado ou servidor local de testes. Não comprometa arquivos grandes no Git comum.

Os recursos enviados pelo Editor do navegador são guardados localmente no IndexedDB daquele dispositivo/navegador; eles não são enviados ao GitHub automaticamente nem sincronizados entre aparelhos.
